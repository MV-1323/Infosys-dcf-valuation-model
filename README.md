# Infosys Ltd. — Discounted Cash Flow (DCF) Valuation Model

## Overview
This project contains a complete DCF valuation model for Infosys Ltd. built in Microsoft Excel.

The model forecasts revenue, EBIT, free cash flow, and enterprise value using a 5-year FCFF projection approach and terminal value methodology.

The valuation includes:
- Historical financial analysis
- Forecast assumptions
- FCFF projections
- WACC-based discounting
- Terminal value estimation
- Net debt bridge
- Implied share price calculation
- Sensitivity analysis
- EV/EBITDA cross-checks

## Objective

To estimate the intrinsic enterprise and equity value of Infosys Ltd. using a Discounted Cash Flow (DCF) valuation framework.
